# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Verbes — a phone-first PWA for daily French conjugation practice: 41 verbs,
fifteen tenses (four literary ones off by default), spaced repetition, all six
persons, no English. Plain HTML/CSS/JS, no dependencies, no build tool, no
Node, no package.json. A sibling of Verbos (the Spanish app, ~/Documents/SpanishVerbs)
but fully independent — never import from it.

## Layout

```
app/            the PWA shell that ships: index.html, engine.js, data.js, frequency.js, sw.js, manifest.json, icons/
tests/          tests.html, tests.js — exercises app/engine.js and app/data.js
scripts/        serve.py, build.py, make_icons.py, mirror.py, count_freq.py — plain stdlib tooling
corpus/         UD treebank downloads for count_freq.py (gitignored)
dist/           generated by build.py (gitignored)
publish/        generated by mirror.py — the exact files deployed to Cloudflare
wrangler.toml   Cloudflare Workers static-assets config — serves publish/
```

## Commands

```bash
python3 scripts/serve.py    # http://127.0.0.1:8766/app/index.html (Verbos uses 8765)
```

Run the tests before and after any change to `app/engine.js` or `app/data.js`:

```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc app/engine.js app/data.js tests/tests.js
```

~1600 assertions. They're written from standard grammar references
(Bescherelle-style tables), not copied from engine output — the engine has to
match them, not the other way around.

After editing anything in `app/`:

```bash
python3 scripts/build.py    # writes dist/index.html (single-file build)
python3 scripts/mirror.py   # writes publish/
```

and bump `CACHE` in `app/sw.js`. Other generators:

```bash
python3 scripts/count_freq.py   # downloads UD French GSD + Sequoia, rewrites app/frequency.js
python3 scripts/make_icons.py   # stdlib only, no Pillow
```

## Architecture

Same five layers as Verbos, loaded as separate `<script>` tags in
`app/index.html` (inlined by `build.py`):

- **`engine.js`** — the `CONJ` module. Pure conjugation logic, no DOM.
  `CONJ.conjugate(inf, tense, person)` gives the primary form;
  `CONJ.variants(...)` gives every accepted form (être agreement — *allée*,
  *allés*; *paie/paye*; 1990 spellings *préfèrerai*, *connait*). The `VERBS`
  table records only deviations; its header comment documents each field.
  Classes are `er` (1st group), `ir2` (finir, -iss-), and `re` (everything
  else — the 3rd group is measured against rendre). Compound tenses are built
  by conjugating avoir/être themselves. `CONJ.irregularity()` diffs each form
  against a regular twin (same class, auxiliary and pronoun, no deviations)
  to classify it as `stem` / `ending` / `spelling` / `participle` / `total`;
  -ger/-cer/-yer changes count as `spelling`, è/ll stem shifts as `stem`.

- **`data.js`** — the `VERB_DATA` module. Sentence frames, grammar notes,
  `check()`. Frames hold no answers. French can't drop the subject, so
  `frameFor(verb, tense, person)` writes the pronoun in front of the blank,
  elided from the answer's first letter (*j'*, *qu'il*); the subjonctif gets
  a trigger clause (*Il faut que*, *Bien que*…). `check()` keeps apostrophes
  and hyphens (they're part of answers), maps the iPhone's ’ to ', and grades
  `correct` / `accent` (shown as *presque*, doesn't advance the box) / `wrong`.

- **`frequency.js`** — the `FREQ` module, generated by `count_freq.py`.
  Per (verb, tense) counts from UD French; compound tenses are counted on the
  participle via its `aux:tense` auxiliary. Used only to order never-seen cards.

- **`app/index.html`** — UI, routing between Exercices / Verbes / Réglages,
  spaced repetition, `localStorage` under `verbes.v1`.

- **`sw.js`** — cache-first service worker. **Bump `CACHE`** whenever a shell
  file changes.

## Working on the engine or data

- Never hardcode a French answer string in `data.js` — add the deviation the
  `VERBS` table needs so the engine keeps deriving it.
- Frames must stay person- and gender-neutral (no possessives, no agreeing
  adjectives) and `neutral` frames must have an empty lead-in, since the
  subjonctif and impératif reuse them.
- After changing conjugation logic, run the full test suite.
